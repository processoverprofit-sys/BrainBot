# Frequently asked questions

## What is BrainBot?

A privately developed, local-first Ubuntu desktop application and user-facing control environment. See the [project overview](../README.md) and [conceptual architecture](ARCHITECTURE.md). Public design objectives are not a verified as-built description.

## Can I download it?

No public application release is available. The repository contains descriptive documentation, not application code, installation instructions or executable software. See the [rights notice](../LICENSE-NOTICE.md).

## Is BrainBot complete?

The historical BrainBot PC 3.5.0–3.5.3 development line is recorded as completed and frozen; the earlier Android direction was discontinued. This does not establish general production readiness, public release or independent certification. See [development status](DEVELOPMENT_STATUS.md).

## Does BrainBot operate T-Bot?

BrainBot and T-Bot are separate projects. BrainBot is not an autonomous trading engine and does not confer trading or signing authority. Any future integration requires its own review and explicit authorisation.

## What has been tested?

The [testing document](TESTING.md) contains fictional, unexecuted examples rather than actual observed results. The [evidence report template](EVIDENCE_REPORT_TEMPLATE.md) contains no evidence.

## Who reviews the work?

The wider portfolio uses owner-led, AI-assisted engineering. AI review is not independent human assurance; no completed independent professional audit is claimed.

## Can I contribute or join Discord?

Read the [community guide](COMMUNITY.md), [contribution policy](../CONTRIBUTING.md) and [central joining guidance](https://github.com/processoverprofit-sys/Processoverprofit-sys/blob/main/docs/COMMUNITY.md#requesting-discord-access). Public Issues and Discussions remain disabled. No verified direct application link has been published.

## How do I report a vulnerability?

Read [SECURITY.md](../SECURITY.md). Use a confirmed confidential route only; never post sensitive details publicly. Private applications and infrastructure are outside the authorised scope.
