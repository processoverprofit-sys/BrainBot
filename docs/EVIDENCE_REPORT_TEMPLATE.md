# Public evidence report template

**Blank template — no tests, actual results or independent assurance are recorded here.**

Use only after actual evidence is reviewed and separately approved for public disclosure. Never attach private logs, resource identifiers, credentials, private source, internal paths or private artefacts. Unknowns must remain unknown.

## Interpretation

Distinguish expected and observed outcomes. Record failures and unresolved questions. A historical version milestone does not establish any example as passed. Isolated results do not establish independent certification, general production readiness or authority to access another project.

No testing, private application access or operational integration is authorised by this template. See the [publication checklist](PUBLICATION_CHECKLIST.md) and [testing methodology](TESTING.md).
